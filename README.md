# Personal Support Worker (PSW) — Professional Healthcare Portfolio

A modern, high-performance healthcare portfolio built with **React 19**, **Vite**, and **Tailwind CSS**.
Engineered with an animated healthcare EKG pulse background, interactive clinical competency monitor, and structured credentials.

## 🚀 Getting Started

1. `cd psw-portfolio`
2. `npm install`
3. `npm run dev`

## 📝 Customization

Update your wife's information in `src/data/portfolioData.js`:
- Name, Title, and Bio
- Clinical Experience & Facilities
- Certifications (VSC, CPR-C, GPA, PSW Diploma)
- Contact details (Phone, Email, LinkedIn)

## 🌐 Custom Domain Deployment

When her domain gets approved:
1. Build the production bundle: `npm run build`
2. Deploy the `dist/` folder to your host (Cloudflare Pages, Vercel, or Netlify).
3. Attach her approved custom domain in the host dashboard.
